# 📱 Criador e Gerador de QR Codes

Este projeto é uma aplicação em **Node.js** que permite ao usuário:

- 🔗 **Gerar QR Codes** com base em links informados.  
- 🔑 **Criar senhas seguras** automaticamente.  

Tudo acontece diretamente no **terminal**, de forma prática e interativa.

---

## 🚀 Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)  
- [chalk](https://www.npmjs.com/package/chalk) → para estilizar saídas no terminal.  
- [prompt](https://www.npmjs.com/package/prompt) → para capturar entradas do usuário.  
- [qrcode-terminal](https://www.npmjs.com/package/qrcode-terminal) → para exibir QR Codes diretamente no console.  

---

## 📦 Instalação e Usabilidade

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/seu-usuario/criador-e-gerador-de-qr-codes.git
cd criador-e-gerador-de-qr-codes
npm install

para iniciar digite no terminal: npm run start
